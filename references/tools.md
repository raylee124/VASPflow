# 优先使用成熟工具

## 发现与选择

VASP 输入生成及后处理优先考虑 VASPKIT；按任务复用已安装的 pymatgen、ASE 等成熟工具，仅在工具不支持或需要特定校验时编写最小补充脚本。不为一项简单工作安装整个科学软件栈。

先查私人档案、`command -v vaspkit`、站点 module 和用户指定安装位置；非登录 shell 中 PATH 缺失不等于未安装。不得为寻找软件遍历未授权目录。用对应版本支持的启动/退出方式做有超时的小检查，记录可执行文件实际路径、版本、架构与配置状态。探测脚本只查 PATH，不承担完整可用性验证。

## 未安装时先请求许可

确认现有 module/路径不能满足任务后，向用户提供具体安装方案并请求许可。明确拟安装的版本、官方来源、远程目标目录、所需依赖、预期配置文件改动和验收方式。资料以 [VASPKIT 官方安装文档](https://vaspkit.com/installation.html) 及其链接的发行源为准，实际安装时重新核实，不能把网页示例版本当作最新版。

优先用户级目录与已有兼容依赖，不默认 sudo、系统库升级或修改共享软件。安装目录不在既有写权限范围、或需修改 home 下 `.vaspkit` 时，在同一安装请求里说明新增路径和范围。一般安装偏好不等于本次安装授权；已批准相同具体方案时不重复请求。未获批准不下载/安装软件，可继续不依赖它的输入检查和计划准备。用户拒绝时说明可用替代方案，只有替代工具适用且在任务范围内才继续。

批准后获取官方发行包，检查平台兼容性、可用的发布校验信息并记录下载哈希；检查安装脚本和解压目标，不能盲执行一键脚本。保存既有相关配置后做最小修改，不覆盖整份配置或无关环境设置。配置势库时必须使用用户合法已有势文件，不下载势文件来补齐安装。若需要额外安装未在方案内的依赖，补充说明变化并取得所需许可。

验收包括可启动、目标功能的小样例输入/输出、必要的势配置，以及实际作业环境中的路径可见性；缺少许可势文件时明确哪些功能尚未验收。记录版本/路径/验证时间和安装范围，不宣称“启动成功”等于全部功能可用。

## 输入生成和后处理

四大基础输入中的分工是：POSCAR 来自已确认结构，INCAR 按具体科学任务编写/审阅；需要新生成或调整的 **KPOINTS 和 POTCAR 默认交给服务器现有 VASPKIT**。已有且适用的参考文件可直接复用并记录哈希，不为调用工具而重写。先查现有环境，不能假定每台机器一定安装了 VASPKIT，也不能因非登录 PATH 缺失直接安装。

1. 在已授权的新草稿目录放好 POSCAR、INCAR；先记录二者哈希。确认 VASPKIT 的版本、启动方式、势库配置及本次势变体映射。
2. KPOINTS：按任务选择网格或能带路径功能，核对当前版本菜单/CLI。官方教程的任务 102 是 SCF 网格示例，103 是默认 POTCAR 示例；这是功能定位线索，不是跨版本硬编码，也不能用 SCF 网格替代能带路径。网格类型、密度、偏移、真空方向采样需要本次方法依据；不要把教程间距作为普适精度。明确选 KSPACING 时不另外生成 KPOINTS。
3. POTCAR：用用户合法持有的势库生成，先确认泛函、版本和每个元素的具体势变体；不能把 VASPKIT 默认推荐映射当成已批准方法。优先使用当前版本支持的指定势功能；避免为一次计算改全局 `.vaspkit`。如果站点配置与目标不符，说明差异并使用受支持的局部方式；需要改 home 配置则先解决新增权限。
4. 生成后独立核对 KPOINTS 网格/权重/偏移或路径、POTCAR 物种顺序/块数量/TITEL/势变体/泛函/版本及哈希，检查未意外改变 POSCAR、INCAR。工具退出码成功而输出缺失、陈旧或不匹配时算失败；草稿目录内的同名旧输出不得充当成功证据。
5. manifest 记录 `input_generation`：每个文件的 `producer`、工具路径/版本、任务号或实际交互输入、输入输出哈希、验证结果；替代生成时记录 `fallback_reason`。VASPKIT 不可用、拒绝安装或功能不适用时，可使用已存在的合适工具/最小脚本，但要明确原因并做相同校验。未解决合法势文件问题时停止提交。

菜单和接口核实依据：[VASPKIT 官方教程](https://vaspkit.com/tutorials.html)。势正文留在服务器，不下载到聊天或技能包；记录的配置/日志也须去掉不必要的私人路径和势正文。

- 在新草稿/后处理目录运行，保护用户参考文件。先明确目标和任务所需文件，再查当前版本任务号与交互序列；不固定沿用其他版本菜单号。
- 保存实际菜单输入、命令、版本、相关配置与输出日志；设置有界超时，交互挂起先诊断所需输入，不能自动重复启动。
- 核查生成文件内容而不只看退出码：结构/元素顺序、势映射、网格、原子数和文件完整性；科学方法与收敛判断仍由工作流负责。
- 后处理记录输入数据哈希、任务号、能量参考、单位、自旋通道及图形定义。工具无法解析的结果标为失败/未知，不补零。大型数据尽量留在服务器，只回传批准的摘要和图。
- 在适合正式科研输出时记录工具版本和建议引用信息；不能把 VASPKIT 成功输出视为上游 VASP 已收敛。
